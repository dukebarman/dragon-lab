A useful archive is not a box of finished answers. It is a room where old observations remain easy to find, compare, and revise.

Don Oren keeps three rituals for every device note:

1. Write the obvious behavior first.
2. Link each assumption to a later test.
3. Return after the first surprise and rename anything that was too confident.

This is why the notes on [interface lanterns]({{< ref "/posts/interface-lanterns/" >}}) and [observatory protocols]({{< ref "/posts/observatory-protocols/" >}}) point back to each other instead of standing alone.
